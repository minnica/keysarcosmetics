# Política de seguridad

## Versiones compatibles

Solo la versión publicada actualmente recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No abras un issue público con información sensible. Usa **Private vulnerability
reporting** en la pestaña **Security** del repositorio de GitHub.

Incluye, cuando sea posible:

- descripción y alcance del problema;
- pasos mínimos para reproducirlo;
- impacto observado o potencial;
- propuesta de mitigación, si existe.

No incluyas datos reales de empleados, tokens, contraseñas ni copias de la base
de datos. La recepción del reporte se confirmará por el mismo canal privado.
