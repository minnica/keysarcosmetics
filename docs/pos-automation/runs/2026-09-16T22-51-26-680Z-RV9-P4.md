  vez;
- pedidos versionados y eventos append-only;
- tickets, pagos, reportes, historial de entregas y conciliación canónicos;
- Scheduler interno, provider HTTP de rollback y diagnósticos;

  Envelope y el reconciliador;

restricción de entrada de una credencial nueva y el contrato servidor ya era
correcto. No se consultó una BD ni se ejecutó una migración.
