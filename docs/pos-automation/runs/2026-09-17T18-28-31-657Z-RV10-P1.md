## Cambios

### `backend/api/scripts/prepare-pos-local-demo.sh`

Helper exclusivo POS/API con cuatro acciones:

- `up`: exige `POS_DEMO_CONFIRMATION=LOCAL_SYNTHETIC_ONLY`, valida el SHA esperado, prepara/inicia PostgreSQL, aplica `prisma migrate deploy`, compila e inicia el API y ejecuta la verificación completa.
- `verify`: comprueba `health.release`, `/ready`, CORS permitido y rechazado, listeners loopback y 46 migraciones terminadas.
- `status`: muestra únicamente estado, SHA y ruta local; no imprime URLs de BD ni secretos.
- `down`: detiene API/PostgreSQL de forma ordenada y conserva el contenedor, la BD y el estado local.

Guardas y aislamiento:

- sólo acepta `127.0.0.1`, `localhost` o `::1` para el API y publica PostgreSQL exclusivamente en `127.0.0.1`;
- exige contenedor `keysar-rv10-p1-*`, base/usuario sintéticos fijos y estado dentro de `.pos-runner/` ya ignorado;
- usa únicamente una imagen PostgreSQL 16 presente localmente y no la descarga;
- genera contraseña/JWT/pepper mediante `openssl`, guarda el archivo con permiso `0600` y no imprime sus valores;
- fuerza un archivo dotenv vacío, Scheduler interno y mensajería deshabilitada: no lee `.env` ni credenciales operativas;
- no ejecuta el seed general, no crea actores/terminales de P2/P3 y no elimina datos al parar;
- falla si un contenedor existente perdió su estado local, si cambia el SHA o si el binding no coincide.

### `backend/api/src/index.ts`
