# Keysar Payroll Terra Palette

Paleta de prueba para `apps/payroll` basada en la serie de tonos proporcionada para esta variante.

## Base

| Token | Hex | Uso |
|---|---:|---|
| Background principal | `#050404` | Fondo general |
| Surface principal | `#080706` | Superficie base |
| Surface elevated | `#0E0D0C` | Tarjetas elevadas y paneles |
| Surface warm | `#17130F` | Capas cálidas y resaltos |
| Border subtle | `#2C241C` | Bordes suaves |
| Border strong | `#5D402F` | Bordes de énfasis |
| Text primary | `#D9D3CA` | Texto principal |
| Text muted | `#655746` | Texto secundario |
| Bronze accent | `#9C846A` | Énfasis cálido |
| Gold accent | `#C5A785` | Acento premium |
| Primary CTA champagne | `#D7B488` | CTA principal |
| Primary active | `#B39671` | Estado activo / hover fuerte |

## Intención Visual

- Fondo casi negro con lectura cálida, no gris frío.
- Superficies apiladas por nivel de elevación.
- Dorado champaña como CTA principal.
- Bronce y oro como soporte para jerarquía, progreso y estados.

## Uso Recomendado

- `Background principal` para todo el canvas.
- `Surface principal` para shells y áreas grandes.
- `Surface elevated` para cards, login y sidebars.
- `Surface warm` para bloques destacados, chips y estados importantes.
- `Border subtle` para límites normales.
- `Border strong` para foco, borde activo o énfasis.
- `Text primary` para títulos y copy principal.
- `Text muted` para metadatos, subtítulos y labels.
- `Primary CTA champagne` para botones principales.
- `Primary active` para hover o estado activo del CTA.
